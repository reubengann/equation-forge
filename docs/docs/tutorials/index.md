# Tutorials

The tutorials progress from basic selection and dragging to complete symbolic
derivations. Start with the first derivation if you have not used Equation
Forge before.

## Start here

1. [Your first derivation](../tutorial.md) — isolate \(x\) using additive and
   multiplicative moves.
2. [Selection and rearranging](selection-and-rearranging.md) — select one or
   several terms and control where they are inserted.
3. [Distribute and factor](distribute-and-factor.md) — apply inverse structural
   rewrites to a product and sum.

## Core workflows

- [Substitution](substitution.md) replaces a selection from another equation
  or from an expression you enter.
- [Operations, identities, and evaluation](operations-identities-and-evaluation.md)
  covers three ways to request more substantial symbolic changes.

## Worked derivations

These longer tutorials apply the same tools to thermodynamics problems adapted
from Sears and Salinger.

- [Enthalpy from an equation of state](enthalpy-from-equation-of-state.md)
  combines two constitutive relations through substitution, cancellation, and
  factoring.
- [Carnot reservoirs](carnot-reservoirs.md) compares reversible heat transfer
  with direct thermal contact and derives the arithmetic–geometric mean
  inequality.

The worked derivations distinguish between steps Equation Forge can perform
directly and steps that must currently be entered manually.
