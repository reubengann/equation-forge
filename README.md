# Equation Forge

![hero](./docs/site/assets/animations/hero_demo.gif)

An application for formula derivation by direct manipulation.

## Quick start

### Jupyterlab plugin

Source: https://github.com/reubengann/jupyterlab-equation-forge

### Stand-alone page

Building from source requires node.js.

```bash
npm install
npm run build
```

Then launch index.html
